# ScaleUp ROI Calculator (Vercel)

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Push to GitHub and import the repo in Vercel.

## Embed
Use:
`/embed`

Example iframe:
```html
<iframe
  src="https://YOUR-VERCEL-URL.vercel.app/embed"
  style="width:100%; min-height:900px; border:0; border-radius:16px;"
  loading="lazy"
></iframe>
```
